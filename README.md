# بدّي وبدّك (Baddi w Baddak)

منصة سورية متكاملة للمقايضة والبيع وإهداء الأغراض المستعملة، مصممة للجوال أولاً باللغة العربية (RTL) وقابلة للتحويل إلى تطبيق Android عبر Capacitor.

## المزايا الرئيسية
- **الرئيسية**: بحث ذكي مع تطبيع الحروف العربية، فلاتر (المحافظة، التصنيف، نوع العرض، نطاق السعر)، وتمرير لانهائي.
- **تفاصيل الإعلان**: معرض صور قابل للتمرير والتكبير، حماية رقم الهاتف بحيث لا يظهر إلا بعد تسجيل الدخول والضغط على «إظهار الرقم» عبر دالة RPC آمنة، مراسلة، اقتراح مقايضة، مفضلة، وإبلاغ.
- **ملف البائع والتقييم الموثّق**: صفحة ملف عام لكل مستخدم (`/user/:id`) تعرض إعلاناته النشطة وتقييماته (من 5 نجوم)، ولا يُسمح بالتقييم إلا بعد وجود محادثة فعلية أو مقايضة مقبولة/مكتملة.
- **أضف غرضاً**: نموذج من 4 خطوات مع ضغط الصور في المتصفح حتى `1600px` وبحد أقصى 6 صور.
- **المحادثات الفورية**: محادثات محمية بين البائع والمشتري تُحدَّث لحظياً عبر Supabase Realtime.
- **المقايضات والمفضلة وحسابي**: إدارة الطلبات الواردة والصادرة، حفظ المفضلة، تعديل الملف الشخصي، وتغيير حالة الإعلان (متاح / محجوز / مغلق).
- **تسجيل الدخول**: برقم الجوال السوري (`09XXXXXXXX`) عبر رمز التحقق SMS OTP من Supabase Auth.
- **لوحة الإدارة**: متاحة للمستخدم المصنّف `admin` لمراجعة البلاغات وإخفاء الإعلانات المخالفة أو حظر المخالفين.

> راجع ملف [`DECISIONS.md`](./DECISIONS.md) للاطلاع على تفاصيل القرارات المعمارية، ونظام الأمان وصلاحيات RLS، وهيكلة التغليف للجوال.

## التقنيات المستخدمة
- React 18 + TypeScript (Strict Mode)
- Vite + Tailwind CSS
- Supabase (Postgres, Auth, Storage, Realtime)
- lucide-react

## خطوات التشغيل محلياً
1. ثبّت الاعتماديات:
   ```bash
   npm install
   ```
2. انسخ ملف البيئة وأضف بيانات مشروعك في Supabase:
   ```bash
   cp .env.example .env.local
   ```
   ثم عبّئ المتغيرين فقط:
   - `VITE_SUPABASE_URL`
   - `VITE_SUPABASE_ANON_KEY`
3. نفّذ كامل ملف `supabase/schema.sql` داخل **SQL Editor** في لوحة تحكم Supabase لإنشاء الجداول، الفهارس، الدوال، المحفزات، سياسات RLS، وتفعيل Realtime وStorage.
4. شغّل التطبيق:
   ```bash
   npm run dev
   ```
5. لبناء نسخة الإنتاج والتحقق من الأنواع:
   ```bash
   npm run build
   ```

> **ملاحظة**: عند عدم ضبط متغيرات Supabase يعمل التطبيق تلقائياً في **وضع المعاينة المحلي** عبر بيانات تجريبية؛ ويمكنك تسجيل الدخول برقم سوري مثل `0944123456` واستخدام الرمز `123456` (أو `000000` لتجربة حساب المشرف).

## خطوات الإعداد اليدوية المطلوبة في Supabase
1. **تفعيل تسجيل الدخول برقم الهاتف (Phone Auth)**:
   - من لوحة تحكم Supabase انتقل إلى **Authentication → Providers → Phone** وفعّل المزود، ثم اربط مزوّد رسائل SMS (مثل Twilio أو Vonage أو MessageBird).
2. **التحقق من Storage Bucket**:
   - ينشئ ملف `schema.sql` حاوية `listing-images` تلقائياً كحاوية عامة للقراءة مع تقييد الرفع بمجلد المستخدم `auth.uid()`. تأكد من وجودها تحت قائمة **Storage**.
3. **تفعيل Realtime**:
   - تأكد من تفعيل Realtime لجدولي `messages` و`conversations` من **Database → Publications → supabase_realtime** (تم تضمين ذلك في `schema.sql`).
4. **تعيين مشرف (Admin)**:
   - بعد تسجيل دخول حسابك الأول برقم الجوال، نفّذ في SQL Editor:
     ```sql
     update public.profiles set role = 'admin' where id = 'USER_UUID_HERE';
     ```

## التحويل إلى Android عبر Capacitor (اختياري)
التطبيق مبني بدون الاعتماد على Web APIs مقيدة، ويمكن تغليفه بتطبيق Android عبر Capacitor:
```bash
npm run build
npm install @capacitor/core @capacitor/cli @capacitor/android
npx cap init "Baddi w Baddak" "com.baddiwbaddak.app" --web-dir=dist
npx cap add android
npx cap sync android
```
